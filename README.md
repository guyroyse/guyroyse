# Who is this Guy?

Hi. My name's Guy. And yes, that's my real name.

Here are a few things about me:

- I'm a hard-boiled geek interested in more things than I have time for.
- I'm husband to my wife of over 30 years and the father of three wonderful young men.
- I'm a rather seasoned software engineer with the gray beard to prove it.
- I'm a public speaker and have spoken about technology all over Europe and North America.

I also do some independent work on the side. If you need an engineer, a teacher of tech, or some fractional developer relations work, check out [my website](https://guy.dev).

## What I'm Into

- **TTRPGs** — I've been playing D&D and other TTRPGs since the early 80s. And I build the model terrain to go with my games.
- **Radio** — I like radio, all those signals out there encoded in invisible light. I'm a licensed amateur radio operator—callsign [W8GUY](https://www.qrz.com/db/W8GUY).
- **Electronics** — I studied electronics in high school—analog and digital—and like building my circuit boards and messing with programmable microcontrollers.
- **Alternative Networks** — I like alternative and decentralized technology like IPFS, Reticulum, and Veilid. I think crypto is kinda neat but I'm not a crypto bro.
- **Linguistics** — I can't get enough etymology in my live. I love learning where words come from and how grammar works. I've studied Latin and Spanish.

But the code interfaces with all of it:

- I taught TDD and pair programming by having everyone code D&D using the [Evercraft Kata](https://github.com/PuttingTheDnDInTDD/EverCraft-Kata).
- I tracked aircraft using a software-defined radio dongle and some [custom-build software](https://github.com/guyroyse/tracking-aircraft).
- I displayed my CPU utilization using an Arduino, a serial port, and an 80 year-old volt meter.
- I built a [web browser](https://github.com/guyroyse/mesh-browser) and [server](https://github.com/guyroyse/rserver) for [Reticilum](https://reticulum.network/).
- I gave a [talk](https://github.com/guyroyse/codex) on how English impacted programming languages and explored what JavaScript might have looked like of it had be created by the Ancient Romans.

And all the code I write for these things. Well, it ends up here on GitHub.
